# Portfolio

Aaryan Basnet's personal portfolio. React 19 + Vite + Tailwind CSS v4 + Framer Motion, deployed to Cloudflare Workers.

## Development

```bash
npm install
npm run dev
```

## Build & deploy

```bash
npm run build    # production build
npm run preview  # build + serve locally via wrangler
npm run deploy   # build + deploy to Cloudflare
```
